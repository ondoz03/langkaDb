# 📋 PLAN v0.3.0: Monetization, Licensing & Feature Control
**Project:** LangkaDB (AetherDB AI)
**Status:** Planning / Roadmap
**Objective:** Mengubah LangkaDB menjadi produk komersial dengan sistem tiering (Free/Pro).

---

## 1. Konsep Tiering
Membagi fitur berdasarkan nilai ekonomi dan biaya operasional (API Token).

| Fitur | FREE Tier | PRO Tier |
| :--- | :--- | :--- |
| **Visual ERD** | View Only | Full Edit & Export |
| **AI Chat** | Rule-Based Only | DeepSeek/OpenAI Access |
| **AI Analysis** | Single Agent (Basic) | **Multi-Agent Orchestrator** |
| **Security Audit** | Peringatan Sederhana | Detail Vulnerability & Fix |
| **Token Limit** | 500 Karakter/Chat | Unlimited (Sesuai Key) |
